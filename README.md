# 여기요!

카드를 한 장씩 뒤집다가 같은 메뉴가 딱 5개가 되면 호출벨을 누르는 2~4인 반응 속도 카드 게임입니다. 각자 폰으로 하고, 방 번호를 넣거나 QR을 찍어 들어오며 빈자리는 봇이 채웁니다.

**플레이:** https://woomars.github.io/yeogiyo/

개인 재미를 위한 비상업 프로젝트입니다. 코드와 직접 만든 그림은 MIT 라이선스([LICENSE](LICENSE))이고, 그 밖의 자료는 아래에 적은 각 라이선스와 권리를 따릅니다. 라이선스 전문은 [vendor/LICENSES.md](vendor/LICENSES.md)에 있습니다. 카드 그림은 직접 그렸고, 소리는 Web Audio로 직접 합성했습니다.

## English

**Excuse Me!** — a reflex card game for 2–4 players: ring the bell when exactly 5 of the same dish show. Everyone plays on their own phone, joining by room number or QR; bots fill empty seats.

**Play:** https://woomars.github.io/yeogiyo/
